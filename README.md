# TECHNOVA — Laboratorio 1
Tienda web estática desarrollada para Programación Web usando HTML5 y CSS3.

## Archivos
- index.html
- styles.css
- assets/logo.svg
- assets/producto1.svg a producto6.svg
- ejecucion.png

## Ejecución
Abrir `index.html` directamente en el navegador o ejecutar:
`python -m http.server 5500`
y visitar `http://localhost:5500`.
